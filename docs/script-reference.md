# 智快问卷脚本参考（简单版）

- 版本：1.0
- 适用范围：智快问卷 JSON Schema v1.0 中的 `script` 字段
- License：MIT

> 本脚本格式参考 Epidata Chk 脚本的设计思路，但只支持本文档列出的子集，不承诺与 Epidata 完全兼容。未列出的命令和函数视为不支持，不应出现在生成的脚本中。当前程序完全由 AI 模型根据用户需求生成脚本，不支持人工编辑。

---

## 1. 概述

脚本用于在填报过程中执行逻辑跳转、字段校验、控件联动等操作。脚本以纯文本形式写在问卷或控件的 `script` 字段中，在数据录入时被解释执行。

脚本在定制问卷时编写，不能在设计阶段看到实际效果，需要通过预览来验证运行时结合问卷数据执行的实际效果。

---

## 2. 快速开始

一个带字段校验的完整问卷：

```json
{
  "schemaVersion": "1.0",
  "title": "年龄调查",
  "questions": [
    {
      "id": "age",
      "type": "integer",
      "title": "年龄",
      "required": true,
      "maxLen": 3,
      "script": "ASSERT age>=18,\"年龄必须满 18 周岁\""
    }
  ]
}
```

一个带跳转逻辑的控件：

```
JUMPS
YES Field_1
NO Field_2
UNKOWN Field_3
END
```

---

## 3. 数据类型

脚本引擎中每个变量（控件的数据）都有类型，共四种：

| 类型 | 说明 |
|---|---|
| 整数 | 不含小数部分的数字 |
| 小数（浮点数） | 含小数部分的数字 |
| 逻辑值（Boolean） | 真 / 假 |
| 字符串 | 文本 |

**日期类型**以 1899-12-31 为原点，按天数存储为小数，便于日期计算（两个日期相减即为相差天数）。

各类型之间可以相互转换，见第 6 节类型转换函数。

---

## 4. 表达式

表达式由数字、算符、括号、变量等组成，用于计算结果。例如：

```
Field_1 + Field_2
```

变量本身也算表达式。赋值语句的右侧可以是表达式，也可以是单个变量：

```
LET Field_1 = 1
LET Field_1 = Field_2 + Field_3
```

其中 `LET` 是赋值命令，通常可以省略。上面的写法等同于：

```
Field_1 = 1
Field_1 = Field_2 + Field_3
```

## 5. 命令参考

### 5.1 ASSERT

在提交问卷时校验数据是否符合要求。有两种写法：

**问卷级（指定字段）：**

```
ASSERT {字段}, {表达式}, "{提示消息}"
```

**控件级（省略字段，自动定位当前控件）：**

```
ASSERT {表达式}, "{提示消息}"
```

当表达式结果为假时，系统显示提示消息，并将焦点跳转到指定字段或脚本所在控件。

**示例（问卷级）：**

```
ASSERT Field_1, Field_1 > 10, "Field_1 必须大于 10"
```

**示例（控件级）：**

```
ASSERT Field_1 > 10, "Field_1 必须大于 10"
```

**组合条件示例：**

```
ASSERT age >= 18 AND age <= 60, "年龄必须在 18 到 60 岁之间"
```

---

### 5.2 DISABLES

声明当控件的取值为某个值时，哪些控件可编辑，其余提及的控件被禁用。块命令，以 `END` 结束。

**编写方式：**

```
DISABLES
{值1} {控件1},{控件2}
{值2} {控件3},{控件4}
END
```

**示例：**

```
DISABLES
1 Field_1
2 Field_2
3 Field_3
END
```

**解释：**

- 当前控件取值为 `1` 时：`Field_1` 可编辑，`Field_2` 和 `Field_3` 禁用。
- 当前控件取值为 `2` 时：`Field_2` 可编辑，`Field_1` 和 `Field_3` 禁用。
- 当前控件取值为 `3` 时：`Field_3` 可编辑，`Field_1` 和 `Field_2` 禁用。

**限制：** 只能写在控件级代码中，不能写在问卷级 BEFORE/AFTER RECORD/ENTRY 代码块里。

---

### 5.3 HIDEROWS

声明当控件的取值为某个值时，显示哪些控件所在的行，其余提及的控件所在行被隐藏。字符串值无需加引号，直接写具体值。块命令，以 `END` 结束。

**编写方式：**

```
HIDEROWS
{值1} {控件1},{控件2}
{值2} {控件3},{控件4}
END
```

**示例：**

```
HIDEROWS
Yes Field_1
No Field_2
Unkown Field_3
END
```

**解释：**

- 当前控件取值为 `Yes` 时：显示 `Field_1` 所在的行，隐藏 `Field_2` 和 `Field_3` 所在行。
- 当前控件取值为 `No` 时：显示 `Field_2` 所在行，隐藏 `Field_1` 和 `Field_3` 所在行。
- 当前控件取值为 `Unkown` 时：显示 `Field_3` 所在行，隐藏 `Field_1` 和 `Field_2` 所在行。

**限制：** 只能写在控件级代码中，不能写在问卷级 BEFORE/AFTER RECORD/ENTRY 代码块里。

---

### 5.4 HIDES

和 `HIDEROWS` 类似，但隐藏的是控件本身（而非所在行）。块命令，以 `END` 结束。

**编写方式：**

```
HIDES
{值1} {控件1},{控件2}
{值2} {控件3},{控件4}
END
```

**示例：**

```
HIDES
YES Field_1
NO Field_2
UN Field_3
END
```

**解释：**

- 当前控件取值为 `YES` 时：显示 `Field_1`，隐藏 `Field_2` 和 `Field_3`。
- 当前控件取值为 `NO` 时：显示 `Field_2`，隐藏 `Field_1` 和 `Field_3`。
- 当前控件取值为 `UN` 时：显示 `Field_3`，隐藏 `Field_1` 和 `Field_2`。

**限制：** 只能写在控件级代码中，不能写在问卷级 BEFORE/AFTER RECORD/ENTRY 代码块里。

---

### 5.5 JUMPS

声明当控件的取值为某个值时，输入焦点跳转到指定控件。块命令，以 `END` 结束。字符串值无需加引号。

**编写方式：**

```
JUMPS
{值1} {控件1}
{值2} {控件2}
END
```

**示例：**

```
JUMPS
YES Field_1
NO Field_2
UNKOWN Field_3
END
```

**解释：**

- 取值为 `YES` 时：焦点跳到 `Field_1`。
- 取值为 `NO` 时：焦点跳到 `Field_2`。
- 取值为 `UNKOWN` 时：焦点跳到 `Field_3`。

**限制：** 只能写在控件级代码中，不能写在问卷级 BEFORE/AFTER RECORD/ENTRY 代码块里。

---

### 5.6 RANGE（命令）

为控件定义允许输入的值范围。值类型需与控件类型一致。

**编写方式：**

```
RANGE {下界} {上界}
```

**示例：**

```
RANGE -5 5
```

允许录入 -5 到 5 之间的数值（含 -5 和 5）。

> **注意：** 此处的 `RANGE` 是命令，与第 6.1 节中的 `RANGE()` 函数不同。后者用于返回逻辑值，参见下文。

---

### 5.7 REPEAT

在连续录入下一条记录时，自动填入上一条记录的值。

**三种写法：**

```
REPEAT           # 使用系统最后填写的值作为默认值
REPEAT USER      # 使用当前用户最后录入的值作为默认值
REPEAT SYSTEM    # 使用系统最后填写的值作为默认值
```

**限制：** 此命令仅在连续录入同一问卷时生效。页面跳转后返回，默认值不保留。

---

### 5.8 其他命令

本文档未列出的命令视为不支持，不能出现在生成的脚本中。

## 6. 函数参考

支持的函数与 Epidata Chk 脚本基本一致，并增加了若干自定义函数。函数调用格式为：

```
函数名(参数1, 参数2, ...)
```

### 6.1 算术函数

| 函数 | 返回类型 | 说明 | 示例 |
|---|---|---|---|
| `ABS(X)` | 小数 | X 的绝对值 | `ABS(-4)` = 4 |
| `ARCTAN(X)` | 小数 | X 的反正切 | — |
| `COS(X)` | 小数 | 角 X（弧度）的余弦 | — |
| `EXP(X)` | 小数 | e 的 X 次幂 | — |
| `FLOAT(X)` | 小数 | 将 X 转换为小数 | `FLOAT("34.3")` = 34.3 |
| `FRAC(X)` | 小数 | X 的小数部分 | `FRAC(3.14)` = 0.14 |
| `INT(X)` | 小数 | X 的整数部分（仍为小数类型） | `INT(3.14)` = 3.0 |
| `INTEGER(X)` | 整数 | 将字符串转换为整数 | `INTEGER("41")` = 41 |
| `LN(X)` | 小数 | X 的自然对数 | — |
| `PI` | 小数 | 圆周率 π | ≈ 3.141592653589793 |
| `POWER(BASE, EXPONENT)` | 小数 | BASE 的 EXPONENT 次幂，BASE 须大于 0 | `POWER(2, 3)` = 8 |
| `RANGE(A, B, C)` | 逻辑值 | 若 B ≤ A ≤ C 返回真 | `RANGE(age, 13, 19)` |
| `ROUND(X)` | 整数 | 四舍五入 | `ROUND(2.5)` = 3 |
| `SIN(X)` | 小数 | 角 X（弧度）的正弦 | — |
| `SQR(X)` | 小数 | X 的平方 | `SQR(4)` = 16 |
| `SQRT(X)` | 小数 | X 的平方根 | `SQRT(16)` = 4 |
| `SUM(变量1, 变量2, ...)` | 小数 | 变量数值求和。范围用引号括起 | `SUM(V1, V2, "V10-V20")` |
| `TRUNC(X)` | 小数 | 截去小数部分，保留整数部分 | `TRUNC(2.5)` = 2.0 |

**补充说明：**

- 三角函数关系中：`Tan(x) = Sin(x)/Cos(x)`，`ArcSin(x) = ArcTan(x/Sqrt(1-Sqr(x)))`，`ArcCos(x) = ArcTan(Sqrt(1-Sqr(x))/x)`。
- `FLOAT` 和 `INTEGER` 常用于配合字符串截取函数使用，例如 `Float(Copy(Field1, 2, 4))` 将字符串 `"Q34.3"` 的第 2 位起取 4 个字符并转为小数 34.3。
- `RANGE` 函数的结果若赋给整数变量，可直接用于条件判断，例如 `LET Teenager = Range(age, 13, 19)`。

---

### 6.2 字符串函数

| 函数 | 返回类型 | 说明 | 示例 |
|---|---|---|---|
| `UPPER(S)` | 字符串 | 转大写 | `UPPER("abc")` = "ABC" |
| `LOWER(S)` | 字符串 | 转小写 | `LOWER("ABC")` = "abc" |
| `COPY(S, INDEX, COUNT)` | 字符串 | 从 S 的 INDEX 位置开始取 COUNT 个字符 | `COPY("My short sentence", 4, 5)` = "short" |
| `POS(SUBSTR, S)` | 整数 | SUBSTR 在 S 中首次出现的位置，未找到返回 0 | `POS("short", "My short sentence")` = 4 |
| `LENGTH(S)` | 整数 | S 的字符数 | `LENGTH("This string")` = 11 |
| `STRING(X)` | 字符串 | 将 X 转换为字符串 | `"sb" + STRING(41)` = "sb41" |
| `SOUNDEX(S)` | 字符串 | S 的声索引编码 | 用于模糊匹配 |

**补充说明：**

- `COPY` 中若 `INDEX` 超出字符串长度，返回空字符串；若 `COUNT` 超出剩余字符数，返回从 `INDEX` 到结尾的全部字符。
- `POS` 未找到时返回 0，不是 -1。

---

### 6.3 日期和时间函数

日期以 1899-12-31 为原点按天数存储，两个日期相减即为相差天数。

| 函数 | 返回类型 | 说明 | 示例 |
|---|---|---|---|
| `DATE(D, M, Y)` | 日期 | 由日、月、年组成日期 | `DATE(22, 2, 2001)` |
| `DAY(D)` | 整数 | D 的日（1-31） | — |
| `DAYOFWEEK(D)` | 整数 | D 是星期几，周一=1，周日=7 | `DAYOFWEEK("22/02/2001")` = 4（周四） |
| `MONTH(D)` | 整数 | D 的月（1-12） | — |
| `NOW` | 日期 | 当前日期时间 | `LET D1 = Now` |
| `NUM2TIME(D)` | 小数 | 将 0-1 的数转为 HH.MM 形式 | — |
| `TIME2NUM(F)` | 日期 | 将 HH.MM 形式转为 0-1 的数 | `TIME2NUM(12.00)` = 0.50 |
| `TODAY` | 日期 | 当天日期 | — |
| `WEEKNUM(D)` | 整数 | D 距当年 1 月 1 日的周数 | `WEEKNUM(Now)` |
| `YEAR(D)` | 整数 | D 的年份（4 位） | — |

**补充说明：**

- `NOW` 和 `TODAY` 是常量式函数，不加括号。
- `TIME2NUM` 示例：`TIME2NUM(0.00) = 0`，`TIME2NUM(24.00) = 1.00`，`TIME2NUM(9.30) = 0.40`。
- `DAYOFWEEK` 编码：周一=1，周二=2，…，周日=7。

---

### 6.4 其他函数

| 函数 | 返回类型 | 说明 | 示例 |
|---|---|---|---|
| `ISBLANK(FIELD)` | 逻辑值 | 变量为空时返回真 | `IF ISBLANK(Field_1) THEN ...` |
| `RECORDPOS(TABLE)` | 整数 | 子表控件中当前行号（从 1 开始） | — |
| `RECORDCOUNT(TABLE)` | 整数 | 子表控件的行数；主表中恒为 1 | — |
| `SELECTIONCOUNT(FIELD)` | 逻辑值 | 多选控件选中项的数量 | — |
| `ISSELECTED(FIELD, V1, V2, ...)` | 逻辑值 | 多选控件是否包含 V1、V2 等值 | `IF ISSELECTED(Field_1, "1") THEN ...` |
| `SELECTNAME(FIELD)` | 名称 | 单/多选控件选中项的名称集合 | — |
| `ID_CARD_DATE(FIELD)` | 日期 | 从身份证号中提取出生日期 | — |
| `YEAR_AGE(BIRTH, AGEDATE)` | 年龄 | 两日期之间的周岁数 | `YEAR_AGE(birth, today)` |

**补充说明：**

- `ISSELECTED` 的 V1、V2 是数据字典保存值，可以是单个值，也可以是多个值。
- `RECORDCOUNT` 用于主表时恒为 1，用于子表时返回当前子表行数。

## 7. 操作符

本脚本引擎的操作符列表如下。与参考实现（Epidata Chk）相比，本引擎只支持以下操作符，未列出的视为不支持。

### 7.1 算术运算符

| 运算符 | 运算 | 数据类型 | 结果类型 |
|---|---|---|---|
| `^` | 指数 | 整数 / 小数 | 小数 |
| `+` | 加法 | 整数 / 小数 / 字符串 | 整数 / 小数 / 字符串 |
| `-` | 减法 | 整数 / 小数 | 整数 / 小数 |
| `*` | 乘法 | 整数 / 小数 | 整数 / 小数 |
| `/` | 除法 | 整数 / 小数 | 整数 / 小数 |
| `div` | 整数除法 | 整数 | 整数 |
| `mod` | 整数除法取余 | 整数 | 整数 |

**补充说明：**

- `+` 用于字符串时执行拼接，例如 `"sb" + String(Field1)`。
- `^` 的结果始终为小数类型。

---

### 7.2 逻辑运算符

| 运算符 | 运算 | 数据类型 | 结果类型 |
|---|---|---|---|
| `not` | 否 | 逻辑值 | 逻辑值 |
| `and` | 与 / 并且 | 逻辑值 | 逻辑值 |
| `or` | 或 | 逻辑值 | 逻辑值 |
| `xor` | 异或 | 逻辑值 | 逻辑值 |

**补充说明：**

- `not` 后只跟一个操作对象。例如：

```
IF not (Field_1 = 1) THEN
  ...
ENDIF
```

---

### 7.3 关系运算符

用于比较两个值，返回逻辑值。建议两侧类型一致；类型不一致时会先转换为同一类型再比较。

| 运算符 | 运算 |
|---|---|
| `=` | 等于 |
| `<>` | 不等于 |
| `<` | 小于 |
| `>` | 大于 |
| `<=` | 小于等于 |
| `>=` | 大于等于 |
